# AI Specification

## Principles
AI is **optional**. The app is fully functional with no provider. AI never computes authoritative metrics. Any UI text produced by a model is labelled "Generated by <provider/model>" and kept visually separate from deterministic text.

## Provider abstraction (`src/lib/ai/provider.ts`)
```ts
interface AIProvider { name: string; model: string; complete(req: {system: string; user: string; maxTokens?: number; json?: boolean}): Promise<string> }
```
Implementations: `openai-compatible` (OpenAI, Azure-compatible gateways, Ollama/vLLM "local model" via `AI_BASE_URL`), `anthropic`, `mock` (deterministic canned output, used for tests; labelled MOCK), none.
Selection via env: `AI_PROVIDER` = `openai|anthropic|mock|none`, `AI_API_KEY`, `AI_MODEL`, `AI_BASE_URL`. If `AI_PROVIDER` is unset but `OPENAI_API_KEY` / `ANTHROPIC_API_KEY` exists it is used; otherwise none.

## Use cases and fallbacks
| Use | AI behaviour | Deterministic fallback |
|---|---|---|
| CSV column mapping | For columns the synonym matcher could not map, ask model to choose from the canonical field list; response validated against whitelist | Synonym + fuzzy token matcher |
| NDR reason normalisation | Classify unknown free text into the fixed reason taxonomy | Keyword rules; else `OTHER` |
| Courier-name normalisation | Not required — deterministic key normalisation; AI suggestions only listed for review | Canonical-key merge |
| Finding / investigation summary | Natural-language explanation from structured evidence JSON | Template text built from evidence |
| Report narrative | Same | Template |

## Safety
Only aggregated evidence or column headers + ≤3 sample values are sent (never full rows or customer PII). 15 s timeout; failures return fallback and a visible "AI unavailable — deterministic output shown" note. Prompts instruct the model to use correlation language and to not add numbers that are not in the input; output is shown as narrative only.
